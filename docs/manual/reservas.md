# Manual de uso de reservas

## Registrar una reserva

1. Inicie sesión con una cuenta autorizada.
2. Abra el módulo Reservas.
3. Seleccione Nueva reserva.
4. Elija un usuario activo y un ejemplar prestado.
5. Confirme la operación. El sistema mostrará el turno asignado.

## Cancelar una reserva

En la lista de reservas, seleccione Cancelar en una reserva activa o notificada. El sistema cambia su estado y reorganiza los turnos restantes.

## Procesar una devolución

La devolución se registra desde Préstamos. Si existe una reserva activa, SIGBU notifica al primer usuario de la cola y muestra la confirmación al bibliotecario.

## Prestar un ejemplar reservado

Después de la devolución, solamente el usuario notificado puede recibir el préstamo. Al completarlo, la reserva queda atendida.
